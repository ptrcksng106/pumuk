# PuMuk (Pukul Nyamuk)

## Description
an iOS game to hit mosquito. built with Vision, SwiftUI. This repo made for me to learn more about vision framework(especially hand gesture) and navigation with navigation stack in SwiftUI.

## Features

- Dashboard
- Gameplay
- GameOver
